# SimplestPYTHONocr
one file 24 line ocr in python

Terminal OCR Reader

A simple Python OCR reader using Tesseract.

## Features

- Extract text from images
- Works from the terminal
- Supports PNG, JPG, JPEG, BMP, and WebP
- Uses Tesseract OCR

## Requirements

- Python 3
- Tesseract OCR

### Arch Linux

Install Tesseract:

```bash
sudo pacman -S tesseract tesseract-data-eng
